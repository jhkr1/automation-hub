# 프로젝트 철학

`automation-hub`는 업무 자동화 기능을 하나의 거대한 애플리케이션으로 합치는 대신,
독립적으로 실행하고 검증할 수 있는 Python 패키지로 축적하기 위해 시작했다.

## RPA에서 Python으로의 재구현 목적

Automation Anywhere에서 수행하던 자동화를 Python으로 재구현하는 목적은 RPA 도구를
대체하거나 우열을 선언하는 것이 아니다. 기존 업무 흐름을 분석하고, 입력·출력 계약,
외부 시스템 경계, 예외 정책, 테스트 가능한 모듈 구조로 다시 표현하는 역량을 검증하는
것이 목적이다.

RPA는 화면 기반 업무를 빠르게 구성하고 비개발자 유지보수에 유리하다. Python은 Git,
단위 테스트, 명시적인 데이터 모델과 세밀한 오류 처리를 적용하기 쉽다. 실제 선택은
업무의 UI 의존성, 외부 API 존재 여부, 운영 환경과 유지보수 주체를 기준으로 판단한다.

## 장기 방향

- 패키지 독립성을 유지한다.
- 확인하지 않은 외부 API나 DOM 구조를 추측하지 않는다.
- 기능 수보다 명확한 계약과 검증 가능한 경계를 우선한다.
- 공통화는 실제 반복이 확인된 뒤에만 수행한다.
